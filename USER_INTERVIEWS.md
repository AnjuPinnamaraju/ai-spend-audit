# User Interviews
I shared the project with two users for informal feedback testing.

# User 1
- Preferred a simpler dashboard layout
- Suggested clearer recommendation visibility
- Found the audit generation flow easy to use

# User 2
- Tested the app on mobile through incognito
- Suggested improving recommendation accuracy based on use case
- Preferred contextual AI tool recommendations over generic outputs

# Key Learnings
- Recommendations should match specific workflows
- Simpler UI improves readability
- Mobile responsiveness is important for usability
